# OCR 校对与 Markdown 规范

## 一、多模式交叉校对

本书 414 页，超出 MinerU flash-extract 的 10MB / 20 页限制，统一使用
`mineru-open-api extract`（需在 https://mineru.net/apiManage/token 申请 token，
`mineru-open-api auth` 配置）。

`make ocr` 会跑两种模式：

| 模式 | 特点 | 用途 |
|------|------|------|
| `pipeline` | 无幻觉，逐字可靠 | **校对基准** |
| `vlm` | 复杂版式（脚注、引文混排）精度更高，偶有幻觉 | 交叉比对 |

校对方法：

1. 以 `ocr/pipeline/` 结果为底稿；
2. 用 diff 工具（如 `diff -u`、`code --diff`）对照 `ocr/vlm/` 结果，
   两处不一致的地方即为疑似识别错误，**对照原 PDF 页面**定夺；
3. 脚注混排、选文缩进等版式复杂处，以 vlm 结果为参照检查 pipeline 底稿；
4. 若需对个别疑难页第三次识别，可用 `--pages N-M` 单页重跑某一模式。

## 二、章节切分

校对后的正文放入 `manuscript/`，**每章一个文件**，文件名以两位序号开头
保证顺序，如：

```
manuscript/00-frontmatter.md     # 电子版说明与免责声明（不进目录）
manuscript/03-preface.md
manuscript/10-chapter-1.md
...
```

pandoc 按文件名排序合并，构建时自动生成目录；`--split-level=2` 把每个 `##` 节
拆成独立 xhtml 文件（即硬分页），脚注按 pandoc 默认行为收集在各节文件末尾。
章标题页只含章题，对应原书的整页章扉页；
章扉页样式由 `scripts/chapter-titlepage.lua` 给章标题加 `.zhang` 实现
（居中横排宋体，「第X章」小字在上——取最大兼容，不用竖排、`:has`、
绝对定位等特性，Boox NeoReader 对仿古籍封面方案会渲染为空白页）。

构建用到的其他过滤器：

- `scripts/newpage.lua`：硬换页标记。正文里独占一行的 `\newpage` 转换为
  空的 `.unlisted` 二级标题，借助 `--split-level=2` 的文件拆分实现换页，
  不依赖 CSS `page-break`（部分阅读器不支持）；空标题不渲染、不进目录。
  注意 `\newpage` 是 LaTeX 命令，会被 `raw_tex` 解析为 `RawBlock`，
  过滤器须处理 `RawBlock` 而非 `Para`（EPUB 输出会静默丢弃前者）。
- `scripts/ascii-heading-ids.lua`：标题锚点改写为 ASCII id（`sec-N`），
  保证各阅读器里目录链接可跳转。
- `scripts/poem-stanzas.lua`：行块里的空行（裸 `|`）视为诗节分界，拆成多个
  行块形成分段；`::: {.poem}` 诗块包成
  `.poem > .poem-inner > .stanza > .line-block` 结构，整块收缩居中、
  诗节垂直堆叠、诗行共享左边缘；EPUB 输出时行块整体序列化成单行原始 HTML
  （`<br />` 后不留换行），避免 Boox 等阅读器把行首空白渲染成缩进。

有序列表使用 pandoc 原生 `<ol start="N">` 输出（Markdown 里被引文隔断后
继续编号的条目会按实际编号输出 start 属性），不做额外改写。

- `scripts/pangu.lua`：盘古之白——在中文字符与西文/数字相邻处插入窄空格
  （U+2009）。阅读器对 `text-autospace` 等 CSS 属性支持极差，插入真实
  字符是唯一可靠方案；已有空格或标点隔开的边界不动。
- `scripts/xuanwen-title.lua`：`::: {.xuanwen}` 选文块首段若以加粗开头
  （诗作题），包为 `.shiti` Div 使标题居中，与 `.poem` 短诗块版式一致。
  不用 CSS `:first-child`/`:has`：无法判断「整段加粗」，且部分阅读器
  不支持 `:has`。
- `scripts/poem-title.lua`：把 `::: {.poem}` 首段加粗诗作题挪出诗块，
  包为 `.shiti`（居中）+ `.heiti`（黑体）——复用 epub.css 既有类，
  不新增 CSS；诗块本身只留诗行，交给 `poem-stanzas.lua`。

- `scripts/fix-nav.py`：构建后处理。pandoc 的目录条目取自正文标题纯文本，
  无法单独指定，而第二至五章作品标题是「篇名[作者]」（篇名在前）。
  此脚本把 `EPUB/nav.xhtml` 与 `EPUB/toc.ncx` 里的条目改写为「作者《篇名》」，
  正文标题版式不变；重新打包时保持 mimetype 为 zip 首个不压缩条目。

## 三、Markdown 书写约定

### 标题

层级与原书目录一致（EPUB 目录深度为 3 级）：

- `#` 章标题、自序、修订版序
- `##` 第一章各篇作品分析标题（如「《关雎》：“乐而不淫”——对于激情的节制」，副标题与主标题同行）；
  第二至五章的主题标题（如「边塞诗：苦寒美、动静制宜美、语气参差美、视听交替美」）；
  第六章各篇文章标题
- `###` 第二至五章主题之下的单个作品：标题在前、作者名以 `[作者]{.zuozhe}`
  行内 span 附后（如「白雪歌送武判官归京[岑参]{.zuozhe}」，作者楷体小一号），
  居中黑体；标题不带书名号
- `####` 及更深：节内小标题——**不进目录**

一句话：凡原书目录里能看到的条目，用 `#`/`##`/`###`；目录里没有的节内小标题一律 `####` 起。

电子版说明与免责声明（`00-frontmatter.md`）标题加 `{.unlisted}`，
使其**不进**电子书目录——原书纸质目录同样不列扉页与版权页。

### 脚注

统一使用 pandoc **行内脚注**，脚注内容直接跟在正文之后：

```markdown
正文文字^[这是脚注内容。]继续正文。
```

不要用 `[^1]` 编号式脚注——OCR 合并多页内容时编号极易错位，
行内脚注没有编号，不存在漂移问题。

### 选文（作品原文引用）

原书版式：选文一律**楷体缩进**，无边框。分四种写法：

诗词选文（每句一行）用 pandoc **行块**（行首 `| `），整体左缩进：

```markdown
| 积雨空林烟火迟，蒸藜炊黍饷东菑。
| 漠漠水田飞白鹭，阴阴夏木啭黄鹂。
```

需要逐行换行、但换行**不是分段**的选文（如杂言古诗摘句），
用块引用内嵌行块（`> | `）：行块保证逐行换行，外层块引用提供选文的楷体与缩进：

```markdown
> | 其险也如此，嗟尔远道之人，胡为乎来哉！
> | 剑阁峥嵘而崔嵬，一夫当关，万夫莫开。
```

词、曲等按段落排的短选文用块引用：

```markdown
> 东城渐觉风光好，縠皱波纹迎客棹。绿杨烟外晓寒轻，红杏枝头春意闹。
```

需要**居中**的诗块只有一种：**篇首主诗**——即紧跟作品标题（`##`/`###`）、
或仅隔一段「解读焦点」导语的那首作品原文，用 `::: {.poem}` 包裹行块，
整块收缩居中、行首共享左边缘：

```markdown
::: {.poem}
| 国破山河在，城春草木深。
| 感时花溅泪，恨别鸟惊心。
:::
```

**其余一切行文中的诗句引文**（含「李白《早发白帝城》：」这类带引导语的），
一律用裸行块 `| ` 左缩进，不要包 `.poem`：

```markdown
李白《早发白帝城》：

| 朝辞白帝彩云间，千里江陵一日还。
| 两岸猿声啼不住，轻舟已过万重山。
```

第一章各篇开头所附的**作品原文**（原书：居中黑体诗作题 + 居中诗块），
诗作题写成 `.poem` 内的加粗段落（由 `poem-title.lua` 挪出诗块居中）：

```markdown
::: {.poem}
**关雎**

| 关关雎鸠，在河之洲。窈窕淑女，君子好逑。
| 参差荇菜，左右流之。窈窕淑女，寤寐求之。
:::
```

各篇开头的「解读焦点」导语，标签用加粗（黑体）后接正文：

```markdown
**解读焦点：** 经典文本分析的难度在于……
```

长选文（含多个段落、标题）用 fenced div：

```markdown
::: {.xuanwen}
**《春望》杜甫**

国破山河在，城春草木深……
:::
```

### 着重号

原书在字下**加点**表示着重（不是加粗）。用 pandoc Bracketed Span：

```markdown
……[谁知]{.zhuozhong}到兰若，流落一书名。
```

渲染分两层：支持 `text-emphasis` 的阅读器显示标准的字下圆点；不支持的
用 `::after` 在文字下方铺「・」模拟。着重号**不改变字体**（随上下文，
楷体选文里的着重词仍是楷体），只靠字下点表示强调。
**只标短词**（几个字），模拟点按宽度截断，不适合整句或跨行长串。

### 落款

题跋、书信等末尾的署名右对齐：

```markdown
[——读者]{.qianming}
```

### 字体分工（由 assets/epub.css 实现，跨平台回退到各系统字体）

| 内容 | 字体 | Markdown 写法 |
|------|------|---------------|
| 正文 | 阅读器默认字体（CSS 不指定） | 普通段落 |
| 章标题（独立章扉页） | 宋体 | `# 第X章 …`（过滤器自动加 `.zhang`） |
| 其他一级标题（自序等，居中） | 黑体 | `# …` |
| 节标题、作品分析标题（居中） | 黑体 | `## …` |
| 主题下的作品标题（居中，不带书名号） | 黑体（作者名楷体小一号） | `### 白雪歌送武判官归京[岑参]{.zuozhe}` |
| 诗作题（居中黑体；短诗由 `poem-title.lua` 挪出诗块、长诗由 `xuanwen-title.lua` 标记首段，均复用 `.shiti`/`.heiti`） | 黑体 | 加粗段落 `**关雎**`、`**陌上桑**` |
| 节内小标题（靠左） | 黑体 | `#### …` |
| 选文、引文、诗歌 | 楷体 | `> `、`::: {.xuanwen}`、行块 `| ` |
| 着重号 | 字下加点（不改字体，随上下文） | `[…]{.zhuozhong}` |
| 扉页信息、题辞、出版说明 | 仿宋 | `::: {.fangsong}` |
| 落款署名 | 右对齐（随正文默认字体） | `[…]{.qianming}` |
| 整页扫描图版（手迹、照片插页） | 居中缩放至一页内（插图全局规则），图注不显示（说明文字留在 alt 属性） | `\newpage` 后 `![说明](assets/…)` |

### 其他

- 强制换页：独占一行写 `\newpage`（`scripts/newpage.lua` 转为文件级硬分页，
  见「二、构建」），不要用 CSS `page-break`（部分阅读器不支持）；
- 行内强调用 `*…*`（排楷体，中文不倾斜）；`**…**` 排黑体；
- 行块的竖线必须是 ASCII `| `，全角 `｜` 不会被 pandoc 解析（OCR 结果容易混入）；
- 书名号《》保留原样，不要改成斜体；
- 页眉、页码、书脊文字等杂质一律删除；
- 拿不准的字，在行间加 HTML 注释 `<!-- 疑：原书作「x」 -->` 留待复核。
